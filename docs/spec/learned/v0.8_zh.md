# 0. 研究问题与一句话

**研究问题**：从“两腿两臂”到“四腿一臂”这种强形态差异下，人-物交互里**哪些功能关系可以保留**？在身体冻结、物体轨迹固定的明确权限下，功能目标能实现多少，需要多大的修改？

**方法一句话**：冻结 X-Morph 的输出作为先验；从人-物示范中提取功能交互目标（碰哪里、什么时候碰、从哪个方向接近）；然后求解先验的正则化臂修正，让机器人实现这些目标。功能对应决定“迁移哪些关系”；交互网格作为待检验的耦合度量，决定“满足不了时怎么折中”。

## 0.1 范围：只做学习式线

| | 学习式线（本文档） | 全优化线（之后） |
|---|---|---|
| 身体怎么动 | 由 X-Morph 决定 | 由优化器从头决定 |
| 课程版的优化变量 | **逐帧基座平面位姿（SE(2)，只在 M 和脚本基线中）+ 6 个臂关节**（v0.8）；12 个腿关节、夹爪角度、物体轨迹不变 | 重新定义身体运动 |
| 迁移哪些关系 | 手 → 夹爪（加场景注册） | 完整的部位-角色对应（§10） |
| 交互网格 | 末端附近，作为待检验的耦合度量 | 全身网格，折中各部位冲突 |

**判据**：目标在上述允许的变量集合中实现不了，就报告这个实例失败或不在覆盖范围内，不悄悄增加自由度。

以后如果开放小幅全身修正，除残差预算外，还必须固定支撑时序、支撑脚身份和世界坐标下的落脚锚点。“不新增落脚点”并不等于“不移动原有落脚点”。

**两条线共享的模块与接口**：

| 模块 | 需要固定的接口 |
|---|---|
| 数据适配 | 单位、坐标系、四元数约定、时间轴、人体与物体同步、原始世界原点 |
| 模式与接触 | 人工标签、工具 patch 和物体 patch、接触区间、法向和置信度（虚拟手：单手，或双手同侧取中点） |
| 几何与评价 | 机器人正运动学和碰撞几何、关节参数、接触与穿透判据、速度和偏差指标、失败记录 |

| 实验输入 | 同一示范划分、候选与排除记录、固定的任务目标和评价参数 |

# 2. 记号与机器人几何

- 帧 $t$，$\Delta t=1/30$ s。物体网格 $\mathcal M$，表面采样点 $\mathcal S$，位姿 $O_t=(R_t,p_t)$；点变换 $[x]_t=R_t^T(x-p_t)$，方向变换 $[u]_t=R_t^Tu$；水平投影记为 $\pi_{xy}$。
- 机器人构型 $q=(T^{\mathrm{base}},\theta_{\mathrm{leg}}\in\mathbb R^{12},\theta_{\mathrm{arm}}\in\mathbb R^{6},\theta_{\mathrm{grip}})$，**$\theta_{\mathrm{grip}}=0$ 锁定（闭合）**。
- **工具坐标系**：gripperStator 坐标系，它相对 link06 的平移为 $(0.051,0,0)$。活动指相对 stator 的铰接点在 $(0.049,0,0)$，绕 y 轴转动，范围 $[-1.57,0]$。
- **接触部位**：$r_c=(0.149,0,0)$，以 stator 坐标系表达。在 $\theta_{\mathrm{grip}}=0$ 时，这个点位于**活动指（mover）的前端面**上（到 mover 网格的距离约 $10^{-9}$ m，到 stator 网格约 9 mm）。前端顶点的外接范围约为 5.2 cm × 2.3 cm（y 约 ±0.026 m，z 约 −0.019 至 0.004 m），但它并不是一个填满的矩形。
- **接触区域**：从真实的前端三角面中指定，并记录它属于哪个连杆（stator 还是 mover）。碰撞白名单同时包含这两个连杆。
- **几何来源**：正运动学用精简模型 `b2_z1_fk.xml`（该文件不含 geom）；碰撞形状从完整模型 `b2_with_z1.xml` 导入，并核对连杆名称与变换。训练罚项和评价使用同一套几何约定。
- **先验**：$q^0=\mathcal X_\theta(G(X^h))$，固定 X-Morph 的提交和 checkpoint。

# 3. 关于先验的观察

- **O1**：网络输入不编码源动作的初始 xy，输出的平移会被重置。但输入文件中仍保存着 `base_trans`，所以**源原点可以通过一个 sidecar 文件保留**。初始 yaw 来自源动作。
- **O2**：速度尺度映射和 0.5 倍转向率是**训练目标里的偏好**，实际漂移需要测量。
- **O3**：先验不输入物体；显式对应和末端监督都偏向右手；夹爪关节的输出没有语义保证，因此锁定为闭合。

# 4. 流程（课程版）

1. **数据与人体侧接触**：选取 OMOMO 片段，人工确认模式、接触区间 $\mathcal T_c$、物体 patch，以及物体局部的接触目标 $\bar c_t$ 和法向 $\bar n_t$。候选的接触标签来源包括 HOI-Retarget 使用的、经 InterMimic 处理的 OMOMO 数据（含逐部位接触标签），可用性和许可待核对。
2. **先验**：GMR → G1 → $\mathcal X_\theta$，得到 $q^0$，同时保存源坐标的 sidecar。
3. **场景注册**：物体几何和示范中的位姿轨迹 $O_{1:T}$ 作为已知输入，**在优化中不更新，但随示范时间移动**。人体、G1、X-Morph 输出和物体轨迹使用同一时间轴。每条示范只求一个恒定的 SE(2)，作用于整条机器人根轨迹；不逐帧拟合，不改变物体轨迹，不补偿高度。
   - **起点锚定**：把输出起点放回源原点（借助 sidecar），yaw 沿用源朝向。这是可复现的默认约定，没有接触帧时也用它。
   - **接触拟合**（主结果）：
   $$
   \min_{\psi,b\in\mathbb R^2}\sum_{t\in\mathcal T_c}\rho_t\big\Vert\pi_{xy}\big(R_z(\psi)p_c(q^0_t)+(b_x,b_y,0)^T-O_t\bar c_t\big)\big\Vert^2+\lambda_\psi\,\mathrm{wrap}(\psi-\psi_{\mathrm{anchor}})^2
   $$
   其中 $\psi$ 是施加在已有根姿态上的**附加旋转**；$\rho_t$ 来自冻结的人工接触标注和置信度；$\psi_{\mathrm{anchor}}$ 是起点锚定对应的附加角度。如果接触轨迹近乎静止、yaw 无法辨识，就固定为锚定角度。注册参数存档，B0、B1、B2、M 全部复用。
4. **功能目标**（§5）。
5. **冻结身体的正则化臂修正**（§6）。
6. **评价**（§7）。

# 5. 功能交互目标

## 5.1 模式与接触

课程版支持人工确认的**同面推动**，接触由**虚拟手**给出（每个片段一种模式）：

| 模式 | 虚拟接触点 | 法向 |
|---|---|---|
| 单手（右） | 右手的接触代理点 | 该手所在 patch 的外法向 |
| 单手（左） | 左手的接触代理点 | 同上 |
| 双手同侧（两只手所在 patch 的法向夹角 ≤ 30°） | 两掌接触点的中点，投影回同一个面 | 该面的外法向 |

**接触高度适配**（v0.7）：侧面和斜面上，接触目标整段沿同一个面做一个恒定的面内平移，把机器人接触高度移进机械臂工作带 $[z_{lo}, z_{hi}]$（离面边缘至少 5 cm）：$\bar c^{\,r}_t=\bar c_t+s\,u$，$u$ 为面内向上方向，$s$ 使接触高度等于 $\mathrm{clip}(z_h,\ \max(z_{lo}, z_{\min}+m),\ \min(z_{hi}, z_{\max}-m))$；法向和沿面的水平位置不变。人的原始接触点保留在记录中，评价同时报告“人的高度”和“机器人的高度”。

双手对夹（两只手在相对的面上）、左右手来回切换（mixed）、非手接触以及 unknown 模式一律排除，并统计排除比例。左手片段：先验偏向右臂，初始臂姿、可达性和残差可能更差，结果按模式分组报告。两只手都不在接触时，虚拟手的掌心取两掌中点（用于接近和撤离路径）。

- **方向目标**不依赖手指弯曲（OMOMO_new 一条片段内手形固定），从 v0.8 起伸出方向取自人的前臂、转角取自手的 roll（§5.4）。**接触点、距离曲线和自动校验**仍然用到人体手部代理，所以以人工确认和校准为准。
- 接触目标 $\bar c_t$ 在物体局部坐标中连续追踪。

## 5.2 功能目标

- **接触位置**：接触期间，$p_c(q_t)\to O_t\bar c_t$。
- **接近方向**（两点版本）：功能点为 $p_c$ 和 $p_c+\ell\,x_{\mathrm{tool}}$；目标为 $\tilde c_t$ 和 $\tilde c_t+\ell R_t\bar x_t$，$\bar x_t$ 为物体坐标中的伸出方向目标（§5.4；手掌不可信时 $\bar x_t=-\bar n$，即 v0.7 的 $\tilde c_t-\ell R_t\bar n_t$）；$\ell=0.05$ m。这里 $\ell$ 是方向误差的杠杆长度，不是硬件尺寸。精确对齐法向是优化里的一个偏好；**$\varphi_{\max}=15^\circ$ 只作为最终方向是否通过的阈值**，锥内的方向误差不为零。
- **法向**：人工指定同一块平滑表面；在物体局部坐标中，对邻域内的外法向加权平均后归一化，再做短时间平滑。邻域不跨越锐边；归一化前向量接近零时，判为不可靠。近似平面的 patch 整段固定一个法向。外法向的朝向由物体网格的朝向统一确定，不能逐帧翻转。首批片段排除尖角、窄棱和法向剧变的区域。
- **接近和撤离路径**：$\tilde c_t=O_t(\bar c_t+d_t\bar n_t)$。**接近时 $d_t$ 降到 0，接触时取 0，撤离时从 0 增大。**掌心到表面的原始距离带有掌厚偏移，用已标注接触帧的距离作零点校准，得到非负的 $d_t$，只做轻微去噪。人的接近和撤离常常不沿法向（R005：手从斜上方落到面上）。这类片段照收，但这部分路径记为“当前路径模板未覆盖”，不算机器人不可达；第一轮可达性诊断只用接触帧。
- **时空权重**：$w=a\cdot c\cdot\kappa$，由 $\mathcal T_c$ 向前、向后扩张后平滑得到（离线、非因果）。B1、B2、M 共用。

## 5.3 交互网格（M）与命题

M 和 B2 共用相同的两点功能目标、门控和损失尺度约定。对每一帧，Laplacian $A$ 在该帧求解期间冻结；两侧的固定物体点相同（不要求整个视频里物体静止）。行权重矩阵记为 $W=\mathrm{diag}(\omega_i)$，$\omega_i\ge0$。则：
$$
E_{IM}=\Vert W^{1/2}A(V-\hat V)\Vert_F^2=\mathrm{tr}(e^THe),\qquad H=A_{:,F}^TWA_{:,F}\succeq0
$$

- **正定性**：$H\succ0$ 当且仅当 $W^{1/2}A_{:,F}$ 满列秩。保留全部正权重行、且每个自由点的连通分量都连到固定锚点时满足；孤立分量、删行或零权重会产生零空间。
- **各向同性（有限定）**：在独立的三维点误差空间里，能量具有旋转不变的块结构，没有显式的法向或切向加权。但交叉项 $2H_{ij}\,e_i\cdot e_j$ 会区分不同的多点误差模式。换到机器人变量后，局部度量变为 $J^T(H\otimes I_3)J$，还要受运动学和约束影响。
- **同解（只对纯任务能量成立）**：在相同的可行集合中，若 $H\succ0$、$D\succ0$，且存在使全部活动目标误差为零的可行解，则两者的最优解集都等于零误差集合。加上先验、残差平滑或罚函数项后，这个结论不自动成立（反例：$E_h=h(q-1)^2+(\lambda_p+s)q^2$，即使 $\lambda_p\to0$，$h$ 不同时解也不同）。
- **均匀权重、按一次性距离算出后冻结的权重、每帧重建但帧内固定的拓扑**，以上结论都成立；按当前机器人位置动态更新权重或拓扑时，不能沿用。
- **能量归一化**：比较前固定 $\mathrm{tr}(H_t)=\mathrm{tr}(D)$，避免把整体任务权重的放大误判为耦合带来的收益。
- **“缩得越小，网格越冗余”只是经验假设，不是定理。**唯一成立的特例是：只有一个自由点且 $H=h$ 固定时，网格就是位置平方误差的标量倍数。

## 5.4 前臂和手给夹爪姿态（v0.8）

**人手坐标系**（每帧，转到物体坐标并轻微平滑）：由手肘 $e$、手腕 $w$、食指根 $i$、小指根 $k$ 得到
$$
f=\frac{w-e}{\Vert w-e\Vert}\ (\text{前臂}),\qquad a=\pm\frac{i-k}{\Vert i-k\Vert}\ (\text{横跨指根，右手 }+\text{、左手 }-),\qquad n^{palm}=\pm\frac{(i-w)\times(k-w)}{\Vert\cdot\Vert}
$$
双手同侧模式取两手的平均后归一化。只用这几个点的相对位置，不用手指弯曲（OMOMO_new 一条片段内手形固定），也不依赖数据里的旋转约定。

**映射到夹爪**（Kevin：人推东西时力沿前臂传过去；夹爪的 roll 对应手的 roll）。抓和按用同一条：

- **伸出方向**（工具 $x$）$=f$，再收进以机器人接触面内法向为轴、半角 $45^\circ$ 的锥内（超出时朝法向转到锥面上），不让夹爪擦着面滑过去；前臂背离物体（与内法向夹角中位数 $>90^\circ$）时取内法向。
- **转角**：Z1 的活动爪绕工具 $y$ 转动，$y$ 取 $a$ 去掉沿 $x$ 的分量，两爪沿 $z=x\times y$ 闭合。手掌平按在面上、前臂顶着推时，$z$ 顺着手指；手扣住桶沿时，$z$ 横跨掌心。
- **只取方向，不取位置**：夹爪是刚体，接触点定了以后，Z1 腕部的位置完全由伸出方向决定；不把 Z1 腕部放到人手腕的位置（两者尺寸不同，会和接触点冲突），与 §5.5“方向来自人，距离来自狗”一致。

**掌心以接触的一侧为准**：接触帧上 $n^{palm}$ 与人的接触面内法向夹角的中位数 $>90^\circ$ 时，把 $n^{palm}$ 和 $a$ 一起取反（`palm_flipped`；R014 的三条双手推为 $149^\circ$–$173^\circ$，可能是数据里手的镜像约定，或 InterMimic 提到的手翻反）。之后夹角 $\le60^\circ$ 才给转角目标；否则不给，伸出方向仍取前臂，并在结果中注明。

**进入求解**：伸出方向 $\bar x_t$ 替换 §5.2 两点目标里的 $-\bar n$，$\varphi_{\max}=15^\circ$ 判定不变（角度相对 $\bar x_t$）。转角为软约束：残差 $w_{roll}(z_{\mathrm{tool}}(q)-R_t\bar z_t)$，$w_{roll}=0.02$ m（小于方向杠杆 0.05 m），**不参与可行性判定**；关节限位使转角够不到时转角让步。报告转角误差的中位数。

**夹爪开合时序**（不区分抓/按）：接近、离面 $d_t\le0.15$ m 时张开；接触时闭合；松开、离面 $d_t\le0.15$ m 时张开；其余时间闭合。接触期间夹爪闭合，接触点 $r_c$ 只在闭合时有效（`configs/b2z1.yaml`）。抓取时的接触部位（两爪之间）另行标定；在此之前只做“按”。

## 5.5 交互网格放置身体（v0.8）

狗的腿和机械臂取自 X-Morph 先验；这一步逐帧决定**身体相对物体放在哪里**，使狗保持人的身体–物体关系，而不只是够到接触点。

- **对应**：人的骨盆 → B2 躯干中心；人的胸 → Z1 底座（joint1）；人的虚拟手 → 夹爪的接触目标（此步视为固定，下一步由臂 IK 实现）。
- **网格**：每帧对人这一侧的点（骨盆、胸、手、物体表面的 $K=24$ 个最远点采样）做 Delaunay 四面体剖分，保留从骨盆或胸到手或物体点的边 $\mathcal E_t$；水平长度不足 5 cm 的边方向不可靠，丢弃。人的点先做 1 s 滑动平均：迁移的是关系，不是步态的左右晃动（R015：网格的额外脚滑仍为 0.4–0.65 m/s）。关系指标也相对平滑后的人计算，三种布局一视同仁。
- **变量**：先验（未注册）每帧的平面位姿 $x_t=(\psi_t,b_t)$，世界坐标 $=R_z(\psi_t)p+b_t$，高度不变；初值为常值注册。
- **能量**（整个窗口一次求解，稀疏最小二乘）：
$$
\begin{aligned}
E=&\sum_t\sum_{(a,j)\in\mathcal E_t}w_m\big\Vert \hat u(P^d_a-F^d_j)-\hat u(P^h_a-F^h_j)\big\Vert^2+w_h\Vert R(\psi_t)f^{d}_t-f^h_t\Vert^2\\
&+w_r\big[(d_t-r_{\max})_+^2+(r_{\min}-d_t)_+^2\big]+w_p(d_t-r^*)^2+w_c\sum_{s}(\mu-\sigma_{t,s})_+^2\\
&+w_s\big(\Vert \pi_{xy}(T_{x_t}p^{tr}_t-T_{x_{t-1}}p^{tr}_t)\Vert^2+(0.5\,\mathrm{wrap}(\psi_t-\psi_{t-1}))^2\big)+w_a\Vert x_t-x^{reg}\Vert^2
\end{aligned}
$$
  $T_x$ 为平面位姿 $x$ 对先验点的变换，$p^{tr}_t$ 为先验的躯干中心：平滑项惩罚放置变化让躯干实际挪动的距离（位姿绕世界原点转动，只惩罚参数差会低估远离原点时的转动，R014 的额外脚滑因此偏大）；$\hat u$ 为水平单位方向；$f^h$ 为人的朝向（两肩连线叉乘竖直方向），$f^d$ 为躯干前向；$d_t$ 为 Z1 底座到接触目标的距离；$\sigma_{t,s}$ 为躯干和腿的采样点到物体凸包的有符号距离。**方向来自人，距离来自狗的手臂**：只用边方向会把身体拉到和人差不多远（物体采样点分布在整个物体上），对手臂太远（合成数据空跑：0.75–0.81 m 不可行，0.60 m 可行），所以加 $r^*=0.6$ m 的距离偏好（R015 中 $w_p=5$ 太弱：人隔着物体去够远侧的棱时，狗被拉到 0.67–0.76 m，三分之一的帧夹爪方向不达标；R016 起 $w_p=20$、$r_{\max}=0.75$ m；R016 中偏好压过了避让，c04 的机身进入箱子 2.8 cm，R017 起 $w_c=40$（距离偏好的两倍：冲突时避让占上风，轻微接触可以容忍并报告）、躯干和腿每个碰撞体取 16 个采样点、$w_s=60$）。权重见 `configs/learned/mesh.yaml`（开发初值）。
- **之后**：臂 IK（§6、§7.1）在放好的身体上求解，与其他布局相同。
- **指标**（所有布局，接触帧）：边方向误差、朝向误差（°），Z1 底座到目标距离，身体进入物体的深度，放置变化带来的额外脚滑（支撑脚，m/s）。

## 5.6 顶面推改到机器人一侧（v0.8）

R013：三条“双手按在顶面上推”的片段，要求夹爪竖直朝下按顶面时全部不可行（最好也偏 $79^\circ$）；只要求位置时，身体跟着物体走的布局能 100% 够到两张桌子。原因有两个：低处的顶面要夹爪竖直朝下，机械臂得折回来；人往下按着推靠摩擦，人能压上体重，机械臂往下压的力有限（Kevin：应该对着竖直面推，或斜着推竖直面和顶面交界的棱）。

规则（只用于“推 + 按 + 人的接触在顶面”）：推的方向、推哪一侧、沿物体横向的位置都来自人；接触挪到机器人这一侧：

1. 取物体在接触期间的水平位移方向 $v$，$u=-v/\Vert v\Vert$ 指向机器人；在人的接触高度上，把每帧的接触点沿 $u$ 推到物体凸包在该高度的最外沿，再投影回网格，得到**棱上的点**（保持沿棱的横向位置）。
2. 棱下方 8 cm 处若有朝向机器人（法向与 $u$ 夹角 $\le30^\circ$）的竖直面，且该面能按 §5.1 的接触高度适配移进侧面工作带，就推**竖直面**（法向取该面）。
3. 否则推**棱**，外法向取 $u$ 与竖直向上的角平分线。伸出方向按 §5.4 取人的前臂，收进以该方向为轴的 $45^\circ$ 锥内，即从竖直向下到水平向前之间（R013 那批桌子和箱子的竖直面不是太矮，就是只有桌面那几厘米厚的边，都走这一条）。

在顶面上往回拖（拉 + 按）暂时不变，仍按在顶面上。结果中记录 `contact_moved`（`rear_face` / `rear_edge`），人的原始接触点保留。

# 6. 冻结身体的正则化臂修正

$$
\min_{\{r_t\}}\ \sum_t a_tc_t\,E^{\mathrm{task}}_t(q_t)+\sum_t\Vert r_t\Vert^2_{W_p}+\lambda_1\sum_t\Vert r_t-r_{t-1}\Vert^2+\lambda_2\sum_t\Vert r_{t+1}-2r_t+r_{t-1}\Vert^2+\sum_j\mu_j\,\mathrm{pen}_j
$$

- $r_t=\theta_{\mathrm{arm},t}-\theta^0_{\mathrm{arm},t}$。$E^{\mathrm{task}}$ 的三种取法：B1 只约束接触位置；B2 用两点直接跟踪；M 用同样的两点目标，换成网格度量。
- **未激活的区间直接返回先验**，同时照常报告先验自身的约束违反。不声称“$a\equiv0$ 时整个目标的最优解恒为 0”。
- **窗口处理**：重叠的扩张窗口先合并；窗口外至少保留两帧 $r=0$ 的边界；用完整序列检查连接处的速度，以及一阶、二阶残差差分。
- **罚函数**：关节限位、关节速度、全部相关碰撞几何（§7.3 的穿透判据，接触部位附近也不豁免）、自碰撞、地面。结果按最终的违反量判定，不声称硬可行。
- **求解**：PyTorch 正运动学加完整模型的碰撞形状；初值 $r=0$；多初值；固定的迭代预算和停止条件。HOI-Retarget 的窗口 NLP（Pinocchio + CasADi/IPOPT）可以作为硬约束版本的实现参考。

# 7. 实验（课程版）

## 7.1 第一项：冻结身体的可达性诊断（go / no-go）

| 项目 | 第一轮口径（开发初值，评价开始前冻结） |
|---|---|
| 单帧位置 IK | 目标误差 ≤ 1 cm，并通过限位和完整碰撞检查 |
| 位置加方向 IK | 在上一行基础上，工具轴夹角 ≤ 15°；另外保存连续的角度值 |
| 关节限位 | 用模型给定的范围；越界容差只作为数值误差，如 $10^{-4}$ rad |
| 实际接触与穿透 | 用 §7.3 的独立判据，不能用位置 IK 通过来代替 |
| 连续区间 | 检查全部帧以及窗口连接处；速度上限向量要配置并注明来源；不能用均值掩盖局部超限 |
| 臂修改量 | 同时报告逐关节最大偏差和全段 RMS 偏差；无预算和有预算（如每关节 20°）的结果分开报告 |

步骤：

1. 人工确认的候选片段（虚拟手的一种模式、同面推动、物体转动 ≤ 45°、适配后的接触高度在机械臂工作带内；接近方向只用于排序），记录所有候选及排除理由（`configs/candidate_selection.yaml`）。R005 的 3 条低处片段作为“冻结身体够不到”的对照保留。
2. 接触拟合注册，$\gamma=1$，物体轨迹固定。
3. 多初值的位置 IK，然后加上方向 IK；“加腕偏好”只作为可选诊断，不参与通过判定。
4. 对有解的片段，检查连续速度、边界拼接和臂修改量。
5. **失败标签**：
   - “规定预算内未找到可行解”（多初值局部优化的失败只能标为这一类）；
   - “已证不可达”（必须有明确的工作空间上界等证据）；
   - “任务不可表达”（只能来自事先确定的任务和模式定义，不能从 IK 失败反推）；
   - “坐标或工具偏移错误”。

3 条片段的结果只用于 go / no-go 判断，不能用来声称 H-A。

## 7.2 主比较

B0（注册后的冻结先验）、B1、B2、M。四者共用输入、注册、初值、权重 $a,c$、可动自由度、约束、调参预算和能量归一化。按逐帧几何可达、连续区间可达、残差预算内可达三层分别标注。

**课程版（v0.8，11/1 收尾）**：三种身体布局 × 同一臂 IK：B0 = 常值注册的先验（`reach_fit`）；脚本基线 = 身体逐帧跟着物体走，只用接触点（`reach_track`）；M = 交互网格（§5.5）。比较可达性（§7.1 的三类问题）、关系保持（§5.5 的指标）和代价（额外脚滑、关节变化）。

结果见 `docs/results/learned_course_zh.md`（R017）。

## 7.3 评价判据

三个相互独立的判断，B0、B1、B2、M 共用：

1. **位置目标误差**：$\Vert p_c(q_t)-O_t\bar c_t\Vert$。
2. **正确接触**：预先指定的工具表面区域与目标物体 patch 的实际表面距离不超过 $\varepsilon_{\mathrm{touch}}$（开发初值 5 mm），并且发生在允许的区间内；接触到错误 patch 单独统计。
3. **穿透**：对完整的相关碰撞几何统一检查，有符号距离需满足 $d\ge-\varepsilon_{\mathrm{pen}}$（开发初值 1 mm），越过即违反，接触部位附近也不豁免。

正确接触和其他部位穿透可以同时成立，两个标签都保留。此外报告限位和速度违反、相对同一先验的修改量、耗时和失败原因；足滑作为继承自基线的指标。

## 7.4 假设

- **H-A**：在固定评价集上，统计冻结身体可达的覆盖率（第一轮只报告 3 条候选的结果）。
- **H-B**：B2 的方向误差优于 B1，且穿透不变差。
- **H-C**：在固定的正则化设置下，检验可达性分层是否影响 M 与 B2 的差异。这是一个经验检验，不是定理的预测。
- **H-D（注册敏感性）**：比较起点锚定与接触拟合两种注册的结果差异；时间漂移另行报告：在同一固定注册下，相对位移和朝向误差随时间的变化。
