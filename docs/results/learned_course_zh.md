# 学习式线课程版结果（v0.2.0，2026-10-30）

规格：`docs/spec/learned/v0.8_zh.md`（§5.4–5.6、§7.1–7.2）。数字来自 R017（Issue #24，代码 `bff364c`，报告在 `reports` 分支 `R017_reach/`），片段、任务和先验来自 R015（#22）。视频：`outputs/R020_reach/videos_mujoco/`（Ubuntu，G1 已修正，见文末），Drive `Human2Dog/runs/R020/`；修正前的是 `R017/`、`R018/`。

## 做了什么

人（OMOMO）→ GMR → G1 → X-Morph → B2-Z1 先验；在此之上：

1. **任务目标**（人这一侧）：虚拟手的接触点和面法向（物体坐标）、接近和离开的距离曲线；接触高度适配；顶面推改到机器人一侧的竖直面或棱（§5.6）；夹爪伸出方向取人的前臂、转角取手的 roll（§5.4）。
2. **身体放置**（三种布局，腿都取 X-Morph 先验）：
   - **先验**：常值注册（`reach_fit`）；
   - **脚本**：身体逐帧跟着物体走，只用接触点（`reach_track`）；
   - **交互网格（我们的）**：逐帧平面位姿，保持人和物体之间网格边的方向与人的朝向，距离由狗的手臂决定（§5.5）。
3. **机械臂**：同一个带避碰的多起点 IK（位置、位置 + 方向、关节预算内），转角为软约束。

## 结果（10 条 OMOMO 推，接触在机器人一侧的顶棱）

| | 先验 | 脚本跟随 | 交互网格 |
|---|---|---|---|
| 全程够到（位置 + 方向） | 3/10 | 9/10 | **9/10** |
| 接触帧中够到的比例 | 68 % | 91 % | 90 % |
| 和人的关系：网格边方向误差中位数 | 8.5° | 10.4° | **6.0°** |
| 身体朝向误差中位数 | 8.6° | 8.6° | **2.6°** |
| 机身进入物体（最深） | 13.0 cm | 4.5 cm | **0.8 cm** |
| 额外脚滑（各任务最大值的中位数） | 0 | 0.29 m/s | 0.63 m/s |

- **够得到**：网格和脚本一样（9/10），都远好于只用先验（3/10）。
- **像人**：差别集中在三条片段：c04 `sub12_largebox_065`、c07 `sub3_largebox_032`、c08 `sub3_largebox_031`。人站在箱子侧面，或隔着箱子去够远侧的棱；脚本让狗站到物体的另一侧（关系误差 47–79°），网格让狗站在人那一侧（5–6°）。其余 7 条人正对物体推，三种布局相近。只看物体轨迹和接触点，得不到“站在哪一侧”这一信息，它只来自人。
- **代价**：网格的额外脚滑约为脚本的两倍。身体被额外挪动，腿仍按 X-Morph 的节奏走。
- **失败**：c02 `sub12_largebox_000`（0.35 m 的矮棱，推 7.8 s）三种布局都够不到，机械臂折下去时撞自己的机身。关节预算内（每个关节在先验上 ±20°）的问题三种布局都是 0/10：X-Morph 的臂姿离需要的姿态很远。

## 局限和留给后面的

- **脚滑**：腿冻结在先验上，只调整身体的平面位置。要么按身体位移重排步态，要么交给全优化线同时求腿和身体。
- **范围**：只做了“按”（推、顶面拖）。侧面拉需要夹住，要先标定两爪之间的接触部位。FORCE 不在先验链中。只做运动学评价，没有物理仿真。
- **评价**：关系指标相对平滑后的人计算，三种布局一视同仁。“全程够到”要求每个接触帧的夹爪轴都在 15° 以内。
- **手**：OMOMO_new 一条片段内手形固定，不用手指弯曲；有的片段手是翻反的，掌心以接触的一侧为准。

## 视频里的 G1（v0.2.1，Kevin 看 R018 视频时发现）

R018 的视频里，G1 嵌进物体 4–23 cm（凸包深度），而且嵌进去的量基本固定。原因有两个：
- **SMPL-X 盆骨偏移**（我们的 bug）：SMPL-X 会把静止姿态下的盆骨关节不经旋转加到 `trans` 上。传给 GMR 的人因此整体偏了 0.35 m（世界 −y 方向），这部分是固定的；
- **GMR 的整体缩放**：GMR 以世界原点为中心，把人的整个场景缩小到 0.83。这样脚不会滑，但 G1 落在人位置的 0.83 倍处，而旁边的物体并没有缩小。

v0.2.1 修正了第一点，并把 G1 和按同样比例缩小的物体画在一起，这正是 GMR 实际所在的场景。修正后 G1 不再嵌入物体，但手悬在物体上方，没有贴上：c01、c08 上，手离表面的中位数是 4–8 cm（在缩小后的场景里量）。在全部 10 条片段上，手部原点比缩小后的接触点高 11–18 cm，水平方向只差 1–13 cm。原因有三点：
- GMR 的 IK 主要跟踪骨盆和脚（位置权重 100），手腕的位置权重在第一轮是 0、第二轮是 10，所以 G1 的手腕离 GMR 自己的目标还差 5–9 cm；
- 手臂缩放 0.74，小于身体的 0.83；
- 有几条片段（c06、c10、c12）里，G1 的骨盆下不到缩小后的高度。

再加上 GMR 不知道物体的存在。视频的 G1 格里已注明这一点（v0.2.2）。要让 G1 真正碰到物体，需要感知物体的重定向，计划在全优化线里用 OmniRetarget 来做。

狗不受这两点影响：X-Morph 只读关节角、朝向系下的根速度和转向角速度，输出从原点开始积分；狗放在哪里，由人和物体决定。

R020（#28，代码 `c0e785b`）用新代码重跑了 D0 → 可达性 → 视频，核对结果如下：
- G1 整体平移了 (−0.003, +0.292) m；
- B2-Z1 先验和 R015 相比，关节角最多差 0.08 rad，根位置最多差 5.5 mm，来自 GMR IK 的数值差异；
- 三种布局在每条任务上能否够到，判定和 R017 完全相同，脚滑也相同；
- G1 穿进物体的帧数：c01 从 47/74 降到 0，c08 从 13/36 降到 0。

起点锚定现在锚在人的起点，注册残差从 0.59–0.81 m 降到 0.21–0.41 m。
