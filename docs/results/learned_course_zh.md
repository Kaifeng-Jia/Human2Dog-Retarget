# 学习式线课程版结果（v0.2.0，2026-10-30）

规格：`docs/spec/learned/v0.8_zh.md`（§5.4–5.6、§7.1–7.2）。数字来自 R017（Issue #24，代码 `bff364c`，报告在 `reports` 分支 `R017_reach/`），片段、任务和先验来自 R015（#22）。视频：`outputs/R017_reach/videos_mujoco/`（Ubuntu），Drive `Human2Dog/runs/R017/`、`R018/`。

## 做了什么

人（OMOMO）→ GMR → G1 → X-Morph → B2-Z1 先验；在此之上：

1. **任务目标**（人这一侧）：虚拟手的接触点和面法向（物体坐标）、接近和离开的距离曲线；接触高度适配；顶面推改到机器人一侧的竖直面或棱（§5.6）；夹爪伸出方向取人的前臂、转角取手的 roll（§5.4）。
2. **身体放置**（三种布局，腿都取 X-Morph 先验）：
   - **先验**：常值注册（`reach_fit`）；
   - **脚本**：身体逐帧跟着物体走，只用接触点（`reach_track`）；
   - **交互网格（我们的）**：逐帧平面位姿，保持人和物体之间网格边的方向与人的朝向，距离由狗的手臂决定（§5.5）。
3. **机械臂**：同一个带避碰的多起点 IK（位置、位置 + 方向、关节预算内），转角为软约束。

## 结果（10 条 OMOMO 推，接触在机器人一侧的顶棱）

| | 先验 | 脚本跟随 | 交互网格 |
|---|---|---|---|
| 全程够到（位置 + 方向） | 3/10 | 9/10 | **9/10** |
| 接触帧中够到的比例 | 68 % | 91 % | 90 % |
| 和人的关系：网格边方向误差中位数 | 8.5° | 10.4° | **6.0°** |
| 身体朝向误差中位数 | 8.6° | 8.6° | **2.6°** |
| 机身进入物体（最深） | 13.0 cm | 4.5 cm | **0.8 cm** |
| 额外脚滑（各任务最大值的中位数） | 0 | 0.29 m/s | 0.63 m/s |

- **够得到**：网格和脚本一样（9/10），都远好于只用先验（3/10）。
- **像人**：差别集中在三条片段：c04 `sub12_largebox_065`、c07 `sub3_largebox_032`、c08 `sub3_largebox_031`。人站在箱子侧面，或隔着箱子去够远侧的棱；脚本让狗站到物体的另一侧（关系误差 47–79°），网格让狗站在人那一侧（5–6°）。其余 7 条人正对物体推，三种布局相近。只看物体轨迹和接触点，得不到“站在哪一侧”这一信息，它只来自人。
- **代价**：网格的额外脚滑约为脚本的两倍。身体被额外挪动，腿仍按 X-Morph 的节奏走。
- **失败**：c02 `sub12_largebox_000`（0.35 m 的矮棱，推 7.8 s）三种布局都够不到，机械臂折下去时撞自己的机身。关节预算内（每个关节在先验上 ±20°）的问题三种布局都是 0/10：X-Morph 的臂姿离需要的姿态很远。

## 局限和留给后面的

- **脚滑**：腿冻结在先验上，只调整身体的平面位置。要么按身体位移重排步态，要么交给全优化线同时求腿和身体。
- **范围**：只做了“按”（推、顶面拖）。侧面拉需要夹住，要先标定两爪之间的接触部位。FORCE 不在先验链中。只做运动学评价，没有物理仿真。
- **评价**：关系指标相对平滑后的人计算，三种布局一视同仁。“全程够到”要求每个接触帧的夹爪轴都在 15° 以内。
- **手**：OMOMO_new 一条片段内手形固定，不用手指弯曲；有的片段手是翻反的，掌心以接触的一侧为准。
